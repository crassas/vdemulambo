# Features Backlog - Véus de Mulambo

> **Funcionalidades Futuras e Melhorias Planeadas**

## 🚀 Próximas Funcionalidades (Backlog)

### 1. Comunicação & Notificações
- **Notificações Push / Alertas em Tempo Real:** Avisos instantâneos via Firebase Cloud Messaging para novos agendamentos ou respostas a consultas.
- **Chat Integrado de Acompanhamento:** Histórico de conversas por texto entre a mentora e o consulente para orientações rápidas.

### 2. Gestão de Clientes Avançada
- **Notas Privadas da Mentora:** Registo confidencial por consulente para acompanhamento personalizado de evoluções espirituais.
- **Histórico de Consultas Realizadas:** Acesso a resumos e datas de consultas anteriores tanto para o cliente como para a mentora.

### 3. Personalização & Conteúdos
- **Sistema de Agendamento por Calendário Interativo:** Escolha direta de horários disponíveis com sincronização automática.
- **Áudio Guiado / Meditações:** Reprodutor de áudio integrado para meditações e rituais guiados pela mentora.
- **Multilíngue:** Suporte para espanhol e inglês, expandindo o alcance da mentoria.
