# POLÍTICA DE PRIVACIDADE

## 1. Dados Recolhidos
Coletamos informações básicas de perfil (nome, email) via autenticação Google e metadados de agendamentos. Todos os dados de pagamento (cartão de crédito) são criptografados e armazenados exclusivamentepela entidade processadora (Stripe). Nunca armazenamos os seus dados de cartão de crédito.

## 2. Uso dos Dados
Os dados servem estritamente para o fornecer os serviços de leitura de cartas e consultoria e não são partilhados com terceiros para fins de marketing.

## 3. Direitos
Pode solicitar a exclusão de todos os seus dados alojados na nossa base de dados Firestore contactando o Suporte.
